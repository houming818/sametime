# S3 多分辨率语言课程 T0 证据报告

日期：2026-10-12

## 结论

本地 Qwen3-8B 在 staged 协议
`full → reduced → short → core` 下，为 512 条固定抽样语料生成了 488 条可解析、
长度严格有序的多分辨率中文候选，接受率为 95.3125%。

该结果支持候选语料生产协议，不证明候选在语义上等价于原句，也不证明
TreeHeap 能学习这些尺度。
