# S3 TreeHeap Structural Differential Atlas

This evidence evaluates one frozen TreeHeap checkpoint on 32,768 held-out real
Chinese 64-token blocks. It compares six perturbations at two disjoint address
settings and reports cross-address classification, depth-energy signatures,
inverse recovery, bootstrap intervals, and sample-size curves.

The result is partial: broad operator families are observable and stable, but
fine WRITE extent and directional Bag/adjacency separation fail. This is not a
semantic, decoder, multilingual, or architecture-superiority result.

See `summary.json` for machine-readable evidence and
`logic/treeheap_structural_differential_atlas.md` for preregistration and the
post-run decision.
