# F10：TreeHeap 有界正交退火显微镜

日期：2026-09-10  
Claim：`S3-TREEHEAP-ORTHOGONAL-ANNEALING-MICROSCOPE-F10`  
状态：smoke r1 已完成；数值与梯度合同通过，观察到一致的左右方向敏感性，未恢复完整句 hard `push`。

## 1. 问题

F04--F09 只沿现有隐态方向做标量放大或缩小。结果证明径向滤镜能够改变 Decode，也发现少数
祖先链具有局部敏感性，但完整西西弗句仍无法生成 hard `push`。因此下一阶梯不再扩大标量
增益范围，而是检验左右子状态之间的方向自由度。

本实验不直接替换正式 TreeHeap，也不训练完整模型。它先回答三个较小的问题：

1. 一个零点严格等于当前 FOLD 的正交参数化能否稳定运行；
2. 左右方向变化能否产生径向增益无法表达的 Decode 变化；
3. 当前冻结 Decoder 是否能够读取正交分解产生的 detail。

## 2. 预注册公式

对有效左右子状态 `l`、`r`，先构造共有分量和差异分量：

\[
c=\frac{l+r}{\sqrt 2},\qquad d=\frac{l-r}{\sqrt 2}.
\]

用有界参数控制方向：

\[
u=0.5\tanh(a),\qquad z=\frac{1}{\sqrt{1+u^2}}.
\]

正交输出为：

\[
p=z(c+ud),\qquad q=z(-uc+d).
\]

`p` 是继续向 root 递归的 parent，`q` 是停留在当前尺度的 detail。它满足：

\[
\lVert p\rVert_2^2+\lVert q\rVert_2^2
=\lVert l\rVert_2^2+\lVert r\rVert_2^2.
\]

当 `a=0` 时，`u=0`，所以 `p=(l+r)/sqrt(2)`，严格回到当前 FOLD。`|u|<0.5` 保证第一阶梯
不会把任一子树权重压到零，也不引入角度周期。

## 3. READ 观察方式

当前 Decoder 每个深度只接收一个同维状态，不能无损地同时接收 `p` 和 `q`。因此固定同一个
递归过程，只改变暴露给 READ 的内部层：

| 模式 | 递归状态 | READ 看到的内部层 | 含义 |
|---|---|---|---|
| native | 当前平均 FOLD | parent | 原始基线 |
| parent | `p` | `p` | 只改变递归方向 |
| detail | `p` | `q` | 诊断冻结 Decoder 能否直接读差异分量 |
| joint | `p` | `(p+0.5q)/sqrt(1.25)` | 受控联合 READ，不宣称无损 |

所有模式的 leaf 层保持原样。`detail` 和 `joint` 只是接口显微镜；它们不等价于最终双通道
架构，也不能以 step-zero 不一致作为失败理由。

## 4. Smoke 合同

- 冻结 E01 第二遍语料的 TreeHeap-106M checkpoint；
- 使用 F08 的单次 `推`、八次重复 `推`、完整西西弗句和四次重复短句；
- 扫描 `a in {-4,-2,-1,-0.5,0,0.5,1,2,4}`；
- base/extra 使用同一方向参数，但分别验证能量闭合；
- 保存固定原生历史 logits、自由生成、`push` coverage/rank/hard hit；
- 只允许硬件、非有限值、冻结参数改变或证据损坏使 smoke 无效。

## 5. 判定

- O0：`parent, a=0` 与 native logits 的最大差不超过 `1e-7`；
- O1：有效节点最大相对能量闭合误差不超过 `1e-5`；
- O2：冻结模型逐 tensor 不变，全部观测有限；
- O3：零点方向参数得到非零有限行为梯度；
- P1：正负方向在至少一个非重复完整句上产生不同 coverage 或 logits；
- P2：若完整句出现 hard `push`，只记录为冻结邻域可达性，不提升为学会翻译；
- P3：若 detail/joint 改善 soft coverage 但没有 hard 文本，只说明 Decoder 对差异分量敏感。

无论 smoke 结果如何，本实验都不授权替换默认 FOLD。只有 O0--O3 通过且方向干预出现可重复的
增量，才设计下一步内容条件化参数训练。

## 6. Smoke 结果

首次任务 `io taskd 401` 在进入干预扫描前因 hard-hit 检查器收到 Tensor 而不是 token list
失败，没有产生结果。该失败保留。只修复输入类型后，r1 任务 `402` 完成全部 112 个条件，
用时 `27.30 s`。输入哈希全部复核通过；GPU 保持 `270 W` 上限，最高功耗 `157.96 W`、最高
温度 `57 C`、最高显存 `872 MiB`，未见 CUDA、OOM 或非有限值。

### 6.1 数值地基成立

| 合同 | 结果 | 判定 |
|---|---:|---:|
| parent 零点相对 native 最大 logits 差 | `0.0` | O0 通过 |
| 最大相对能量闭合误差 | `2.713e-7` | O1 通过 |
| checkpoint 冻结且全部观测有限 | 是 | O2 通过 |
| 零点方向梯度最大绝对值 | `0.261143` | O3 通过 |

因此这套公式不是只有正向数值闭合：Decoder 的行为损失能够沿方向参数反传非零有限梯度，具备
进入后续训练的最低工程条件。

### 6.2 方向不是对称的

`parent` 模式在最大正负扫描端得到：

| 输入 | native coverage | 负向 `u=-0.4997` | 正向 `u=+0.4997` |
|---|---:|---:|---:|
| 单次 `推` | `0.000469` | `0.000783` | `0.000227` |
| 完整西西弗句 | `0.000428` | `0.000712` | `0.000124` |
| 重复西西弗短句 | `0.001265` | `0.002028` | `0.000867` |

三个未饱和输入都表现为负向增加、正向减少，且自由生成文本发生不同变化。完整句因此通过 P1：
冻结 checkpoint 中的左右组织不是可交换的，正交参数能够观察到有符号的路由方向。这仍不能
证明负向是普遍语言规律；同一中文语序、同一 checkpoint 和选择最大扫描端都可能造成方向偏置。

### 6.3 soft 可达性提高，hard 生成未越界

各模式在九个扫描点中的最佳 coverage 为：

| 输入 | native | parent 最佳 | detail 最佳 | joint 最佳 |
|---|---:|---:|---:|---:|
| 单次 `推` | `0.000469` | `0.000783` | `0.001138` | `0.000808` |
| 八次重复 `推` | `1.000000` | `1.000000` | `1.000000` | `1.000000` |
| 完整西西弗句 | `0.000428` | `0.000723` | `0.000589` | `0.000867` |
| 重复西西弗短句 | `0.001265` | `0.002038` | `0.001498` | `0.001969` |

P3/P4 通过：parent 方向、detail 和联合 READ 都存在 soft coverage 增量。但完整西西弗句没有
任何模式生成 hard `push`，P2 不支持。部分 coverage 提高时最佳 token rank反而变差，说明
coverage 是跨生成时域累计概率，不等价于某一步的 argmax 排名。冻结 Decoder 输出仍是
`Westin/Westminster/mountain` 一类邻近文本，不能称为恢复了正确翻译。

## 7. 当前结论

F10 支持有界正交退火作为**可训练的方向参数化候选**：它严格复现旧零点、数值闭合、梯度有限，
并测得一致的左右符号敏感性。F10 不支持直接替换默认 FOLD，也不支持“只旋转就能恢复组合
语言”。`detail` 的强 soft 响应说明差异分量中存在 Decoder 可感知信号，但当前单状态 READ
接口不能无损地同时传入 parent/detail。

下一阶梯应保持冻结 checkpoint，训练一个零初始化、内容条件化的小型方向头，并与参数量匹配的
径向头配对；训练目标同时观察 coverage、rank 和 hard generation。若方向头只能继续提高 soft
coverage 而不能改善 held-out 组合文本，就停止该航线，而不是继续放大角度。
