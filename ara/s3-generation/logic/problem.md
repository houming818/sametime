# S3: TreeHeap Generation

## Core Question

Can TreeHeap internal structure drive controllable surface generation?

## Status

Planned / first system hypothesis registered.

## Key Ideas

- S3 consumes TreeHeap states, probability containers, routes, and internal
  subheaps as generation programs.
- Echo is only a regularizer; generation should not be constrained to pure
  input reconstruction.
- The first S3 system claim is `S3-SEM-HUFF-GEN-C01`: train TreeHeap as a
  semantic Huffman generation code.
- The first proof must require structure: same bag of words, different
  TreeHeap attachment/path, different generated surface output.
