# F09：TreeHeap 祖先链与上层跳跃显微镜

日期：2026-09-10  
Claim：`S3-TREEHEAP-ANCESTOR-JUMP-MICROSCOPE-F09`  
状态：smoke 已完成；重复输入扩展 parent/祖先链得到观察支持，局部路径敏感性存在，标量径向干预未恢复完整句 hard `push`。

## 1. 问题

F08 发现重复输入“推”能够生成 `push`，而单次“推”和包含“推石头”的完整句不能。一个可否证
解释是：重复的相似 leaf 在递归合并时形成更稳定的 parent，并把 `push` 方向送入更粗层；当前
单 parent 滤镜未能复现这个逐层积累过程。

F09 不训练模型，而是直接观察以下四种干预是否具有不同结果：

1. 单个 parent 的跳跃干预；
2. 从一个 fine parent 到其所有有效祖先的连续链干预；
3. 与祖先链坐标数和幅度相同、但不在该链上的对照；
4. 所有有效 parent 的统一增益对照。

## 2. 固定对象

- checkpoint：E01 第二遍语料的 TreeHeap-106M；
- theta：F04 r1 的冻结退火参数；
- 输入：单次“推”、八次“推”、完整西西弗句、四次“西西弗推石头”；
- Decoder：自由生成与固定原生历史都保存；
- 模型、theta、词表和数据均不更新。

## 3. 干预方程

每个有效递归 parent 的原计算为：

\[
p_{d+1,j}=\frac{l_{d,j}+r_{d,j}}{\sqrt 2}\,g_{\theta,d,j}.
\]

滤镜在 parent 刚形成时施加：

\[
p'_{d+1,j}=p_{d+1,j}
\exp\!\left(\log(1.5)\tanh u_{d,j}\right).
\]

扫描 `u ∈ {-4,-2,-1,-0.5,0.5,1,2,4}`，覆盖接近允许范围 `(2/3,1.5)` 的抑制与放大。
同一 `u` 写入 base 与 extra 的同一递归坐标。连续祖先链由固定二叉拓扑计算，不根据 Decode
结果选择。离路径对照使用相同数量、相同幅度的其他有效坐标。

## 4. 观测量

逐次保存：

- `push` phrase coverage；
- `push/pushing/pushed/pushes` 的最佳 token rank 与概率；
- 是否在自由生成中出现完整目标 token 序列；
- 固定历史 logits 相对原生状态的最大变化；
- 自由生成文本；
- active parent、merge、node、祖先链和滤镜能量。

## 5. 预注册解释

- 上层单点跳跃出现 `push`，祖先链不出现：当前 coarse 状态可读，但递归形成过程不足。
- 祖先链优于等能量离路径对照：支持路径连续积累，而不只是总增益。
- 重复输入的原生状态已经出现 `push`，且上层/祖先干预进一步敏感：支持重复信号进入 coarse
  parent 的观察，但不证明其唯一原因。
- 路径与离路径没有稳定差别：当前标量滤镜仍主要是能量旋钮。
- 所有径向干预均无法令单次或完整句出现 `push`：不能据此否定更高容量的向量旋转，只否定
  当前冻结 checkpoint 邻域内的标量径向调焦。

这是显微镜实验，不以一次样本证明通用语义路由，也不据结果替换默认架构。

## 6. Smoke 结果

运行：`io` taskd `400`，seed `12001`，耗时 `194.2 s`，共 `852` 个直接 Decode 条件。模型与
theta 逐 tensor 冻结、数值有限、base/extra active 拓扑一致，GPU 始终保持 `270 W` 功率上限。

### 6.1 重复确实改变了递归可用空间

| 输入 | source pieces | 有效 parent 坐标 | 最长有效祖先链 | 原生 hard push |
|---|---:|---:|---:|---:|
| `推。` | 4 | 1 | 1 | 否 |
| `推` 重复八次 | 18 | 15 | 4 | 是 |
| 完整西西弗句 | 14 | 11 | 4 | 否 |
| `西西弗推石头` 重复四次 | 26 | 23 | 5 | 否 |

这支持“重复输入会产生更多 parent，并使相似信号有机会沿多层递归聚合”的结构观察。它还不能
单独证明上层聚合是 `push` 出现的唯一原因，因为重复同时改变了长度、局部上下文和 Decoder
看到的整体状态。

### 6.2 单次 `推` 没有可调上层

单次 `推。` 只有坐标 `0` 有效，因此 fine 单点与 uniform-all 实际为同一个旋钮。完整增益扫描
把 `push` coverage 从 `0.0004577` 最多提高到 `0.0004911`，最佳 rank 从 `43` 到 `40`，文本
始终是 `The following is the example.`。这不是上层调焦失败，而是该输入根本没有独立的有效
上层 parent 可供调节。

### 6.3 完整句的上层跳跃不足以越过 hard 门槛

完整西西弗句中，任一上层单点或祖先链都没有生成 `push`。上层单点可把最佳 token rank 从
`11` 改善到 `5`，但 coverage 最大仅从 `0.001149` 到 `0.001270`。祖先链最大 coverage 为
`0.001211`，反而低于离路径对照可达的 `0.001307`；48 个配对条件中祖先链只赢 14 个，均值
差为 `-0.000195`。因此该句不支持普遍的“沿祖先链放大优于其他等能量节点”。

### 6.4 重复短句出现局部强路径

`西西弗推石头` 重复四次仍未原生生成 `push`，但某条五节点祖先链
`5 -> 18 -> 25 -> 28 -> 30` 在 `u=+4` 时把 fixed-history `push` coverage 从 `0.002546`
提高到 `0.019237`，约 `7.56` 倍；同样五个坐标、同样幅度的离路径对照只有 `0.002739`，统一
放大全部节点为 `0.010547`。96 个链/离路径配对中，祖先链赢 44 个，平均差 `+0.000998`，说明
收益集中在少数路径，而不是所有祖先链共同成立。

这个结果支持“存在局部、路径相关的 coarse 读出敏感性”，但仍没有 hard `push`，自由生成也
没有恢复正确翻译。当前标量滤镜能够找到焦距方向，尚不足以把隐态旋转到目标词的生成区域。

## 7. 结论边界

F09 支持：重复输入扩大了有效递归坐标；部分祖先链比等能量离路径干预更强。F09 不支持：任意
上层节点都携带 `push`、标量上层增益足以修复完整句翻译、或已找到可泛化的语义路径。下一步
若继续，应先为 leaf/Butterfly 坐标建立到 parent 的可追踪映射，再测试通道组或低秩向量旋转；
继续扩大同一标量增益没有新的可用范围，因为本次已经扫描到接近 `(2/3,1.5)` 的边界。
