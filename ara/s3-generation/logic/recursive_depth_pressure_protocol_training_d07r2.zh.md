# D07R2：有界协议增益

状态：预注册，等待 proof。

Claim：`S3-RECURSIVE-DEPTH-PRESSURE-PROTOCOL-D07R2`

## 修正依据

D07R1 中 shuffle 已稳定损害 NLL 约 `0.6`，说明协议不是常量；但 zero 更好约 `1.4`，
说明协议被以错误幅度直接写入冻结 decoder。R2 不改变协议内容、压力容量、FOLD、数据
或损失，只在协议槽位进入 FOLD 前加入一个共享有界增益：

```text
g_protocol = sigmoid(a),  a_init = -4
slot_used  = g_protocol * slot
```

`g_protocol` 被所有深度和槽位共享。它从约 `0.018` 开始，允许梯度在“零上下文参考点”
附近逐步引入协议，而不是一开始满幅覆盖冻结 decoder 的旧坐标。

## Predict

- R2-P0：source 与语言骨架哈希不变，增益为有限的 `(0,1)` 标量。
- R2-P1：至少两个深度 valid NLL 比初始化下降 `>=0.10`。
- R2-P2：至少两个深度的 shuffle 和 zero 相对 native NLL 都增加 `>=0.10`。
- R2-P3：容量增加不系统性伤害重建，沿用 D07 的 `0.05` 容差。
- R2-P4：两端 READ 梯度非零，增益梯度非零，最终增益没有被推到数值边界。

若 R2-P2 失败，则“样本相关但参考点错误”不足以解释 D07R1，停止该协议槽位设计的
正式扩容。


## Smoke 结果

taskd `330` 完成 600 steps。共享增益从 `0.01799` 学到 `0.02039`，没有贴近 0 或 1；
source 与语言骨架哈希保持不变，两端 READ 和增益都有非零有限梯度。

valid NLL 的变化为：

| depth | 初始化 | 训练后 | 下降 |
|---:|---:|---:|---:|
| 5 | 6.194 | 6.076 | 0.118 |
| 6 | 6.193 | 6.055 | 0.138 |
| 7 | 6.196 | 6.059 | 0.138 |

最重要的因果消融已经改变方向：

| depth | shuffle 相对 native | zero 相对 native |
|---:|---:|---:|
| 5 | +0.096 | +0.036 |
| 6 | +0.139 | +0.071 |
| 7 | +0.142 | +0.064 |

native 在全部深度都优于 zero 和 shuffle，说明压力协议第一次同时出现弱输入信息收益与
样本身份收益。但是预注册 R2-P2 要求至少两个深度的两种消融都达到 `+0.10`；zero
消融只有 `+0.036` 至 `+0.071`，所以严格判定仍为：

```text
smoke_blocks_formal
```

生成 BLEU4 约 `0.642`，没有相邻重复，但不同深度的样例基本相同，尚未形成可见的
分辨率语义差异。当前证据支持“有界增益修复了协议的符号方向”，不支持“私有协议已
足够强”或“模型已经学会缩句”。依据预注册规则，不继续追加 steps 追逐门槛。
