# F02：让 TreeHeap 自己学习显微镜焦距

日期：2026-09-08
Claim：`S3-FOLD-FOCUS-TRAINING-F02`
状态：初始 smoke 保留为失败记录；smoke r1 通过；正式 taskd `372` 已完成；P0/P1 通过，P2/P3/P4 未支持。

## 1. F01 留下的问题

F01 冻结 TreeHeap-106M，并在九档 FOLD 尺度上完成 1080 次直接解码。它证明观察尺度会
因果地改变成句、EOS、长度和文本内容，也观察到 depth 6/7 的字符相似度焦点集中在
`0.707..0.8`。但 F01 没有训练，所以没有回答：梯度能否自己找到焦距。

F02 只新增三个参数：

```text
u_d = tanh(theta_d)
s_d = sqrt(0.5) + (1 - sqrt(0.5)) * u_d,  u_d >= 0
s_d = sqrt(0.5) + sqrt(0.5) * u_d,        u_d < 0
parent = s_d * (left + right)
```

初始时 `theta_d=0`，三个 `s_d` 都严格等于 `sqrt(0.5)`；该坐标在两侧保持连续并将尺度
限制在开区间 `(0,1)`。106M checkpoint 的其余参数全部冻结，
`K_up` 保持原生状态。这样，任何变化只能来自三个焦距参数，而不是语言模型重新记忆语料。

## 2. 为什么先做三参数训练

直接开放样本级调焦器会同时引入控制网络、额外容量和新的过拟合路径，无法知道收益来自
“学会焦距”还是“多了一个模型”。三参数深度调焦是最小可训练原型：

- 能检验 CE 梯度是否对不同递归深度给出不同方向；
- 能观察 F01 的焦平面是否会在训练中被模型主动选择；
- 失败时只否定这一种低自由度参数化，不否定自适应焦距本身。

## 3. 训练合同

- 基座：E01 TreeHeap-106M pass-2，step 132873；
- 基座 checkpoint 全程只读，并用原 trainable-state SHA-256 审计；
- 训练参数：仅 `theta_5, theta_6, theta_7`，共 3 个；
- 数据：`NioClean-ZHEN-S098-7M-v2` 的确定性前向流，WMT 固定 valid/test 对从训练流排除；
- batch 64，固定 5,000 steps，约 32 万训练样本暴露；
- depth 5/6/7 循环训练，使三个参数得到近似相同更新次数；
- AdamW，学习率 `1e-3`，无 weight decay；
- 每 500 steps 固定 wake；训练质量非单调不提前停止；
- 仅 OOM、CUDA/Xid、NaN/Inf、基座哈希改变、重载失败或步数无法推进允许停止。

Smoke 使用同一实现跑 30 steps、两个固定标本。Smoke 通过后才提交 5,000-step 正式任务。

## 4. 评价合同

训练使用 token CE 提供梯度，但 Claim 不只看 NLL。每个 wake 对 F01 锁定的 20 个标本，
在三个 depth 上直接 greedy Decode，记录：

- 原始生成文本；
- EOS 与非空率；
- 输出长度及参考长度比；
- 相邻重复率；
- dependency-free character F2 diagnostic。

另在固定 WMT valid/test 上记录 mean NLL、PPL、BLEU、非空率和重复率。20 个标本从不进入
训练，也不能根据输出改写。

## 5. 预注册判定

### P0：同起点

训练前可学习调焦器与原生 `sqrt(0.5)` 的 valid NLL 差不超过 `1e-9`，20 句直接输出逐字
一致；否则实验无效。

### P1：梯度能到达焦距

三个 depth 参数都至少一次得到绝对值大于 `1e-12` 的有限梯度，最终尺度仍在开区间
`(0, 1)`，基座哈希不变且 checkpoint 可重载。

### P2：是否形成深度分化

若最终任意两个 `s_d` 相差至少 `0.02`，记录为“深度相关焦距已被训练选择”；否则记录为
“当前损失偏好共享焦距”。两种结果都必须保存，不作为安全停止门。

### P3：预测性能

相对 step 0，固定 valid mean NLL 改善至少 `0.01`，才支持“三参数焦距具有可测预测收益”。
不足则记录为未支持，不据此中断 5,000 steps。

### P4：直接 Decode

若 20 句平均 character-F2 上升，同时 formed rate、EOS rate 均不下降超过 `0.05`，记录为
“焦距训练改善直接读出候选”；否则记录具体交换关系。成句不等于翻译正确，字符 F2 也不
冒充标准 chrF。

## 6. Claim 边界

F02 不证明样本级调焦已经解决，不把三个标量称为新的完整 FOLD，也不允许直接替换产品
架构。它只回答一个阶梯问题：在冻结语言与结构参数后，训练信号能不能推动不同递归深度
选择自己的观察尺度，并在直接 Decode 中留下可见结果。

## 7. Smoke 失败记录与 r1

初始 taskd `370` 完成了全部 30 steps，但 P0 失败。直接生成文本逐字一致，NLL 差仅
`3.110864e-8`；原因是旧参数化先计算 `logit(sqrt(0.5))`，再用 float32 `sigmoid` 返回，
无法位级复现 Python 常数乘法。其余门全部通过，三层也都获得非零有限梯度。

不放宽 `1e-9` 的 P0 门槛。r1 改用上述以 `sqrt(0.5)` 为绝对零点的双侧有界坐标，
`theta=0` 不经过逆函数往返。失败 evidence 保留在
`evidence/s3_fold_focus_training_f02/smoke_seed11401/`，r1 写入独立目录。

Smoke r1 taskd `371` 完成 30/30 steps，P0 与全部安全门通过。三层都收到非零有限梯度，
基座哈希不变，checkpoint reload NLL 误差为零。30 步尺度从共同的 `0.70710677` 分化为：

```text
depth 5: 0.70969760
depth 6: 0.70627469
depth 7: 0.70328337
```

valid mean NLL 改善 `0.00102895`。两个 smoke 标本的 formed rate 保持 `1.0`，字符 F2
尚未变化；该结果只授权固定 5,000-step 正式训练，不提前支持 P2--P4。

## 8. 正式结果

taskd `372` 在 `io` 的 RTX 3090 上完成固定 `5,000/5,000` steps，样本游标推进到
`320244`，墙钟时间 `6490.14` 秒。10 个预定 wake 均存在，step 序列为
`500, 1000, ..., 5000`；trace 从 step 1 连续记录到 step 5000。GPU 采样始终记录
`270 W` 功率限制，未出现 OOM、CUDA/Xid、NaN/Inf 或证据损坏。

正式判定如下：

| 门 | 结果 | 证据 |
|---|---|---|
| P0 同起点 | 通过 | step-0 valid NLL 差为 `0`，60 条 depth 展开直接输出逐字一致 |
| P1 梯度到达 | 通过 | 三个 depth 均收到非零有限梯度；基座哈希前后一致；reload NLL 差为 `0` |
| P2 深度分化 | 未支持 | 最终尺度为 `[0.71405345, 0.70080888, 0.70542419]`，最大差 `0.01324457 < 0.02` |
| P3 预测收益 | 未支持 | valid mean NLL `3.85521275 -> 3.85463181`，改善 `0.00058094 < 0.01` |
| P4 直接 Decode | 未支持 | character-F2 `0.14186604 -> 0.14115761`，变化 `-0.00070844`；formed `0.9333 -> 0.9333`，EOS `0.9667 -> 0.9667` |

焦距在训练中持续振荡，而不是收敛到三个稳定分离的深度值。训练确实能够通过 token CE
驱动这三个坐标，但在当前学习率、循环深度采样和冻结基座下，5,000 steps 没有得到
预注册要求的预测收益或直接读出改善。

因此 F02 支持一个窄结论：**深度焦距是可微、可训练、可重载且不会改变冻结基座的协议
坐标。** 它不支持“只靠三个全局深度标量就能学出有效的深度专属焦距”。这三个参数不进入
默认架构；若继续研究，需要先解释振荡来源并预注册新的优化或条件化机制，不能把本次结果
追认为成功。
