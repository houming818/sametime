## Status Rules

| Status | Meaning |
|---|---|
| `verified` | Evidence exists and includes baseline or falsification checks |
| `supported` | Positive pilot evidence exists, but scale or baseline is incomplete |
| `open` | Plausible but not yet tested |
| `design` | Mathematical / architecture proposal only |
| `rejected` | Tested and failed |

## Soft TreeHeap

| ID | Claim | Status | Evidence | Falsification |
|---|---|---|---|---|
| M0-SOFT-C01 | Hard TreeHeap operators can be expressed as probability-lifted soft operators: `SoftO(H)=sum_a p(a)O_a(H)`. | design | `logic/soft_treeheap.md` | One-hot soft operation fails to recover the hard operation. |
| M0-SOFT-C02 | Soft Plus is the correct differentiable extension of TreeHeap write; naive soft memory write is too weak as a TreeHeap algebra claim. | supported | `logic/soft_treeheap.md`, `evidence/soft_plus_probe/` | Naive slot interpolation is formally shown equivalent to TreeHeap plus, or Soft Plus cannot train. |
| M0-SOFT-C03 | Kernel-guided Soft Plus can receive gradient through `K_write` and `Plus_a` in a synthetic toy. | supported | `evidence/soft_plus_probe/summary.json`: `dL/dK_write=0.0902425`, `dL/dPlus=0.143869` | Either gradient norm is zero/NaN under deterministic rerun. |
| M0-SOFT-C04 | Kernel-guided Soft Plus can collapse to the correct hard plus address at low temperature in the synthetic toy. | supported | `evidence/soft_plus_probe/summary.json`: `collapse_accuracy_tau_0.05=1.0` | Low-temperature collapse accuracy falls below 1.0 under deterministic rerun. |
| M0-SOFT-C05 | Kernel-guided Soft Plus is better than naive memory write or generic encoder soft plus. | open | Planned write-mechanism ablation | Naive memory write or encoder soft plus matches/bests kernel-guided soft plus on accuracy, collapse legality, and OOD relocation. |
| M0-SOFT-C06 | Multi-kernel staged training is more stable than a single big-pot loss. | open | Planned loss ablation | Big-pot loss is more stable and generalizes better under matched budget. |
