# 有界旋转搜索

状态：预注册设计
Claim：`M0-ROT-C01`
Predict：`P-ROT01`
日期：2026-07-21

## 要验证的问题

一棵有序 TreeHeap 切片，能否经过可靠的旋转算子和 `CAT` 递归扩展，
同时继续由同一个固定大小的搜索 kernel 精确读取？

递归定义为：

```text
H_(n+1) = CAT(H_n, R_n(H_n))
```

这里的 `R_n` 不能只是随意复制。它必须可以求逆，保持旋转切片内部的
顺序，让新旧切片之间存在可比较的区间边界，并且只保存旋转描述符，
不必复制全部数据。

查询时，kernel 比较目标与右侧切片的边界。如果进入旋转分支，就先做
`R_n^-1`，把问题变回上一层，再继续递归。旋转层全部退回后，同一个
二分搜索 kernel 在基础切片中找到目标。

## 复杂度不能偷换

旋转 `n` 次以后，逻辑候选数是：

```text
M_n = |H_0| * 2^n
```

一次查询需要：

```text
n 次旋转分支判断 + O(log |H_0|) 次基础切片判断
```

所以它对递归深度 `n` 是线性的，对候选总数 `M_n` 是对数复杂度。
它不是对 `M_n` 的线性扫描，也没有免费生成或求解任意指数空间。

显式复制需要 `O(M_n)` 的数据空间；懒惰 TreeHeap 只保存基础切片和
`n` 个旋转描述符，即 `O(|H_0| + n)`。

## 可学习 kernel

归纳实验只训练一个两参数逻辑回归比较器：

```text
x = (query - right_min) / current_range
p(right | x) = sigmoid(w*x + b)
```

它只看浅层旋转数据，然后原封不动地用于更深层。输入里有 query 和
节点区间，但没有“目标在左边/右边”的答案布尔值。因此它验证的是共享
比较规则能否外推，不是语言智能。

## 对照组

1. `explicit_sorted`：复制全部旋转切片，准确但空间指数增长。
2. `unordered_scan`：破坏顺序后逐个比较，准确但查询变成线性扫描。
3. `broken_rotation`：打乱旋转切片内部的数据位置，再沿用原来的单路径
   kernel。若仍然成功，就说明实验没有真正利用有序结构。
4. `budget_exceeded`：请求超过硬上限的一次旋转。必须返回
   `BUDGET_EXHAUSTED`，不分配空间，也不给出猜测答案。

## 预期

基础切片为 31 个元素，测试到 16 层旋转：

```text
P1 确定性精确检索率             = 1.0
P2 学习 kernel 的深度外推准确率  >= 0.999
P3 逆变换和路径等变准确率         = 1.0
P4 最大查询步数                  <= n + ceil(log2(31)) + 1
P5 第16层懒惰/显式空间比          >= 1000
P6 破坏旋转后的单路径准确率        <= 0.10
P7 超预算状态                    = BUDGET_EXHAUSTED
```

## 证伪条件与边界

只要精确代数恒等式失败、学习 kernel 不能从浅层外推到深层、懒惰表示也
随候选数指数增长，或者打乱顺序不影响单路径搜索，就否定这个 claim。

本实验不证明语言语义、不创造新信息、不搜索任意无结构空间、不破解密码，
也不声称比较次数优于完整物化的有序数组。它只验证：规则且保序的旋转轨道，
能否被 TreeHeap 用很少的结构描述复用。
