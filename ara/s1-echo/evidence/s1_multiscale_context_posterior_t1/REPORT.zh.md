## 结论

T1 的三个注册 Claim 在 20K smoke 和 200K formal 中均通过。现有证据支持：

1. T0 学到的上下文分区不只适合整行共现检索，也能用于 held-out 句子中的
   masked-token 条件推断。
2. 增加上下文会降低候选 token 后验熵；在正式数据中，同时降低 gold NLL。
3. 四分箱的粗尺度已经显著优于同容量随机分区，信息并非只存在于最细叶层。

这仍然不是句义压缩、FOLD/READ 私有协议或文本生成证据。

## 正式合同

- 语料扫描：200,000 行 WMT 英文侧。
- 训练/测试：源行号模 10，余数 0 为 sealed held-out。
- 目标/context 词表：8,192 / 4,096。
- 事件：50,000 个配对 masked-token 事件，每个都有四个词表内邻近上下文。
- 上下文顺序：距离升序，同距离时左侧优先。
- 尺度：1 / 2 / 4 / 8 / 16 bins。
- 控制：三棵平衡随机树、词频先验、4,096 context-ID 未压缩参考。

## 新发现

未压缩参考的 NLL 为 `6.250681 -> 5.714359 -> 6.044044`。第四个上下文使
后验继续变尖，但预测反而变差，说明邻近词并不条件独立，直接相乘会重复计算
相关证据。20K smoke 的 Tree 也出现过较小的 `m=2 -> 4` 反弹；200K formal
中 Tree 的四上下文 NLL 仅轻微改善。

因此，下一步不是声称“上下文越多必然越好”，而是给上下文证据增加独立的
校准合同，例如 power posterior、重复 bin 去重或按距离衰减，并使用分离的
development/test 行选择校准参数。
