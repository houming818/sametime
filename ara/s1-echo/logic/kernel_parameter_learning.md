# S1 Kernel Parameter Learning

Status: planned
Created: 2026-06-30
Owner: nio / Houming818
Review Engineer: Codex

## Problem

SPR-038 proved only state relaxation:

```text
H <- H - eta * grad_H E(H)
```

It did not prove kernel parameter learning:

```text
Theta <- Theta - eta * grad_Theta L(K_Theta(H))
```

Houming818's correction is that model parameters themselves should be allowed
to be TreeHeap objects. In that framing, the next proof must distinguish:

| Symbol | Meaning |
|---|---|
| `Theta` | parameter TreeHeap, the learned kernel carrier |
| `H` | activation / memory TreeHeap for one sample |
| `A` | physical address rule, e.g. `left(i)=2i`, `right(i)=2i+1` |
| `K_Theta` | TreeHeap convolution kernel defined by `Theta` |
| `L` | scalar loss used to produce gradients |

## Claim

`S1-KERNEL-LEARN-C01`:

A parameter TreeHeap `Theta` can learn a local subheap convolution rule from
loss/gradient. In the minimal scalar case, training should recover the hidden
kernel weights used to generate target internal-node states.

## Predict

`P-S1-KERNEL39`:

Given complete binary heaps of depth 2:

```text
        h1
      /    \
    h2      h3
   /  \    /  \
 h4   h5 h6   h7
```

and hidden kernel:

```text
theta* = [1, 1, 1]
```

targets are generated by:

```text
y1 = 1*h1 + 1*h2 + 1*h3
y2 = 1*h2 + 1*h4 + 1*h5
y3 = 1*h3 + 1*h6 + 1*h7
```

The learned parameter TreeHeap should recover:

```text
Theta ~= [1, 1, 1]
```

and produce low test/OOD MSE on unseen heap values.

## Minimal Experiment

1. Generate random scalar heaps `H`.
2. Generate targets with hidden kernel `[1,1,1]`.
3. Train `Theta=[theta_root, theta_left, theta_right]` by gradient descent.
4. Compare to:
   - no-learning baseline
   - wrong-address baseline
   - flat linear baseline
5. Report:
   - learned theta
   - theta error
   - train/test/OOD MSE
   - whether wrong address fails

## Extension

After the scalar proof passes, test vector kernels:

```text
H'[i] = W_root H[i] + W_left H[left(i)] + W_right H[right(i)]
```

Then test multi-kernel variants:

```text
K_1: sum kernel
K_2: difference kernel
K_3: mirror kernel
K_4: stop/left/right route kernel
```

## Falsification

Reject or downgrade if:

1. `Theta` does not recover the hidden kernel under clean scalar data.
2. Test/OOD error stays high.
3. A wrong-address baseline performs the same.
4. A flat baseline wins without using address/path/subheap structure.
5. The proof only updates `H` and does not update `Theta`.

## Boundary

This proof would not prove language understanding or translation.

It would prove a smaller but necessary point:

```text
TreeHeap kernel parameters can be learned by gradient, while the operator
still uses address/path/subheap structure.
```
