# SaTi/学习目标与计划

## 一、学习目标
- **阶段目标**：通过公开评估级（benchmark）量化模型能力，建立基线参考
- **技术路线**：学习 LLM 结构/微调/评估/部署全栈，实现可复现、可复用的模型方案

## 二、公开评分级（Benchmark）列表

| 名称 | 领域 | 说明 | 参考范围 |
|------|------|------|----------|
| MMLU | 知识/推理 | 多任务选择题，涵盖医学/法律/物理等 | 60-80% |
| MMLU-pro | 专业题 | 需要专业知识的长推理题 | 70-85% |
| GSM8K | 数学 | 需要多步推理的数学题 | 60-80% |
| MATH | 纯数学推理 | 高难度奥数/竞赛题 | 50-70% |
| HumanEval | 代码生成 | Python 函数填空 | 60-70% |
| BIG-bench | 多任务 | 多语言多能力的测试 | 70-85% |
| HellaSwag | 常识推理 | 上下文填空 | 80-90% |
| ARC | 认知推理 | 视觉-文字结合推理题 | 60-70% |
| TruthfulQA | 真实性 | 防幻觉检测 | 75-85% |
| BBH | Big-Bench Hard | 高难度推理 | 70-85% |

## 三、学习路线图（按月度）

### 第一个月：基线建立（入门）
- 目标：在通用领域达到开源模型 60-65%（MMLU）
- 任务：
  1. 模型准备：拉取 LLaMA-3 8B/70B
  2. 数据准备：清洗公开数据集（COT-10K、MMLU）
  3. 微调：使用 LoRA 简单微调
  4. 评估：跑通评估脚本，记录分数
- 交付物：基线模型、评估报告

### 第二个月：优化迭代（进阶）
- 目标：提升到 70-75%（MMLU）
- 任务：
  1. 数据增强：加入更多高质量训练数据
  2. 微调策略：调整学习率、batch size
  3. 多任务微调：同时训练多个任务头
  4. 对比评估：与开源模型（Qwen/GLM）对比
- 交付物：优化模型、对比报告

### 第三个月：专业级目标（精通）
- 目标：达到专业级水平（MMLU-pro 75%+）
- 任务：
  1. 领域微调：医疗/法律/代码等场景
  2. 知识蒸馏：小模型优化推理速度
  3. 集成测试：部署到 ZooDeploy
  4. 真实用户反馈循环
- 交付物：专业版模型、部署文档

## 四、评估与迭代流程

1. **初始化**：用开源模型作为基线，跑通评估脚本
2. **迭代**：每次微调后重新评估，记录分数变化
3. **归档**：将每次评估数据上传到 vector 数据库，用于分析趋势
4. **回滚**：分数下降时立即回滚到上一版本，分析原因

## 五、资源清单

- 数据：
  - MMLU 训练集/测试集
  - HumanEval 评测集
  - GSM8K 数学题

- 工具：
  - LLM 训练框架（PyTorch/DeepSpeed）
  - 评估脚本（Hugging Face eval）
  - 部署脚本（Docker/ZooDeploy）

## 六、注意事项

- 实验与生产隔离，避免影响现有服务
- 每次评估记录实验日志，便于追溯
- 遵循开源协议与合理使用规范
